# README notes for the lead (MOBILE, 0.4.1) — suggested text, zh-TW

## 操作方式 table: replace the W/A/S/D-less rows / add:
| W／A／S／D | 直接移動；施放遠程攻擊與法術時也能邊走邊出手（速度較慢） |
| 按住 Shift | 原地出手（不追向目標，施法時也站定） |

## Paragraph under the table (after 「點擊攻擊範圍外的敵人時…」):
**邊走邊打：** 遠程攻擊與法術（箭矢、法術投射物、連鎖閃電、地面法術、詛咒、陷阱、召喚物指令）出手時，仍可用 W/A/S/D
或按住滑鼠左鍵移動，移動速度降為 65%，箭矢與法術仍飛向瞄準的目標或地點；按住攻擊鍵瞄準敵人、同時按移動鍵後退，就能邊退邊射。
近戰攻擊、衝鋒、跳躍、旋風斬與增益技能仍會站定。可在「設定 → 遊戲 →施法時可移動」關閉，恢復出手時停下腳步的方式。

## 0.4.1 changelog line:
- 新增「施法時可移動」：所有職業的遠程攻擊與法術可邊走邊放（移動速度 65%），上半身出手、雙腳照常行走或後退；可於設定關閉。AI 代打的遠程職業會邊退邊射、邊閃避邊射。
